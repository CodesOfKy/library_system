LibraryMap (Godot 4)

1. Extract this zip.
2. Open Godot 4 -> Import -> choose project.godot -> Import & Edit.
3. Copy server/map_api.php to C:\xampp\htdocs\000CAPSTONE\
   Run server/library_map.sql in phpMyAdmin (SQL tab).
4. Start Apache and MySQL in XAMPP, then press F5 in Godot.

Click a shelf or use the search box to see the arrows from the entrance.
